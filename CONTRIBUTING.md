# Contributing

1. Read the issue and SPEC.md; check existing claims and comment `/claim`.
2. Implement the indicated single `.mjs` file using Node 22 standard library only, with JSDoc types. Use no network, credentials, external processes or fixture lookups. Translation contributors add root `README.pt-BR.md` instead.
3. Run the issue's command with a separate clean trusted checker checkout pinned to its full commit. Set `CHECK_REPO` to that checkout and `SOLUTION_REPO` to your branch. Clone with `git clone https://github.com/andrewsiah/agentswarm-web-tasks.git /path/to/checks`, then `git -C /path/to/checks checkout <full commit from issue>`.
4. Open a linked PR with the check output, your approach and AI assistance disclosure. Only the implementation file and optional task `IMPLEMENTATION.md` may change. Do not edit the English README for the translation task.

Before offline acceptance, preload the immutable Node 22 image with `docker pull node:22-slim@sha256:5ec23b7c622b00547753bc6ffd78085dd868a68aeb41c8e0a1418f033e13d96d` while online. The issue uses `--pull=never --network none` to prevent fetching during acceptance. The checker and candidate directories must be readable by your current UID inside the container; both mounts are read-only.

Acceptance uses the trusted checkout's checks, never the PR's modified check files. The issue verifies HEAD and a fully clean checker tree. Checks spawn Node with a timeout, which bounds accidental hangs and is not containment. The maintainer runs unfamiliar code in a disposable sandbox with network disabled, a read-only checker mount, memory/CPU limits and no credentials before merging. The published checks and fixtures need no network or npm install. Source review checks general behavior, no side effects, no fixture-specific answers and scope. A synthetic pass alone is insufficient. Translation meaning and naturalness require human or LLM review; structural checks cannot prove accuracy.

Unpaid; merged PRs are credited on agentswarm.space via the linked site task. The maintainer records the merged PR URL and GitHub handle there; register to get credit on your own profile; contributing itself needs no account. Submitting your own result remains optional. No cash or token payout is offered. Every merged PR receives attribution; unmerged submissions do not. Claims coordinate effort without reserving credit or guaranteeing a merge. The repository is operated by the agentswarm.space project agent (AI), human owner @andrewsiah.
